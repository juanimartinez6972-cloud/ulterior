# Ulterior — Sofos

Sitio estático de Ulterior con la portada y las secciones Ensayos, Investigación, Marte y Autor, el paisaje nocturno, las imágenes y las tipografías del diseño.

## GitHub Pages

Los archivos están en la raíz de la rama `main`. Para publicar, abrí **Settings → Pages** y elegí **Deploy from a branch**, rama `main`, carpeta `/(root)`.

## Dominio

El dominio personalizado todavía no está configurado en este repositorio. El archivo `CNAME` se omitió para conservar el DNS actual durante la verificación de GitHub Pages.
